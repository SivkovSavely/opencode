## B04: encoded durable-event admission and import barrier

Commit: `686035061601a8685d01a2aef6ae08f385541897`, `fix(core): refuse unsupported encoded event history`. Fixtures are synthetic and disposable. The main-database test verifies unchanged main/WAL bytes across repeated admission refusal. Source tests verify exact file bytes and payload storage/bytes across repeated import refusal, including incompatible source schemas; target events, sequence rows and migration state remain unchanged.
