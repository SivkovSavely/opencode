## B03: snapshot full-diff input safety

Blob metadata is batched without loading file content into JavaScript; submodule commit objects are not queried. Git still computes numstat, so this does not claim to eliminate all large-file scanning or diff-count computation.

Its regression now uses six individually eligible 2 MiB files instead of one file that the new input guard must skip. Patch path selection remains literal, case-sensitive and command-line bounded, and separates file/directory replacements so selecting a small parent path cannot recursively reintroduce an oversized descendant. Descendant-only exclusions preserve eligible gitlink parents. Snapshot capture and restore still retain the underlying tracked file data.

This is a deliberately partial F022 batch. No diagnostic writer, JSONL sampler, recovery instrumentation, public skipped-reason field or UI indicator was added. An empty patch with nonzero counts is not proof of an unchanged file.
