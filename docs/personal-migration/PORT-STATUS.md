### Architecture And Decisions

- Core owns a disposable per-message/part/category `transcript_document` projection, FTS5 trigram candidate index, and durable `transcript_state`. Native schema generation produced migration 61. Atomic service initialization installs write/FTS triggers before any historical cursor advances. Source changes, normalized-part changes and index maintenance share SQLite transactions, including rollback and physical revert cleanup. The source is native `session_message` plus `session_part`, never serialized whole-message search.
- Explicit backfill processes at most 200 message or part source records per call, persists its phase/cursor, survives reopening, and does nothing once ready. Search/status never backfill. Explicit rebuild clears only derived documents/state, retains tracking and source history, and invalidates cursors immediately and upon reaching readiness. Search limits final candidate examination to 500, category content to 65,536 SQLite characters, and excerpts to 80 UTF-16 context units. Empty hit pages can still continue.
- Tracking rebuilds the affected message on a source write rather than adding an asynchronous dirty queue. One message can contain many parts or large public input, so 200 sources/500 candidates are count bounds, not latency/memory guarantees. Facets scan historical metadata independently of text-index readiness. ASCII candidates use trigram narrowing plus a non-ASCII-body correctness fallback; non-ASCII candidates use bounded final scanning because SQLite folding cannot safely replace JavaScript Unicode matching. No benchmark, snapshot or exactly-once claim is made.
- Public experimental routes are `/api/experimental/transcript/{search,status,backfill,facets}`, identifiers `experimental.transcript.*`, through existing authenticated Server boundaries. Schema owns browser-safe contracts, Core the database service, Protocol the endpoints, and Server delegation/error mapping. Client code never imports Core/Server. Native Client generation was run after the last public change; generated outputs were not manually edited.
- O-01 is fixed with an OR of intended role/category pairs, additionally narrowed by the independent role filter. O-02 excludes the staged revert tail from both search and facets, while clear restores it and committed deletion removes derived rows transactionally. O-03 uses strict source identity, one bounded message refresh for a missing part and localized unavailable/history-failure feedback; no sibling substitution. O-04 uses canonical `aborted`/`tool.interrupted` evidence and explicit durable-shell states, not wording, idle outcome or private replay metadata.
- The global titlebar and `mod+shift+f` open one native desktop/mobile dialog. Title-only search and current-session Ctrl+F/F003 remain separate. - Multi-origin merging compares buffered heads before emission, retains safe prefixes and successful buffers on failure, retries the same failed cursor, rejects cyclic continuations, permits at most eight empty requests per required origin per invocation, and ignores aborted generations.
